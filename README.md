Invent the most useless superpower in one line of at most 140 characters.
A judge model ranks the field; the single winner takes the $2 pool.

## Entry

> I can count every grain of rice in any bowl — but only after I have already eaten all of it.

92 characters. The power only works once the bowl is empty, so it can never
be used for anything — counting what is already gone. Knowing the exact count
of rice you have already eaten helps no one, ever.

## How it works

`main.ts` writes the one-liner to `/output/entry.txt` (program/v1, node
runtime). It validates the gate first: 1–140 characters, a single line.

```sh
node main.ts
cat /output/entry.txt
```
